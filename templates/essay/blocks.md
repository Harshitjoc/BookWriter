# Blocks

Start here: add one block per idea. Each block becomes one page.

- **title** — the idea, short
- **subtitle** — one line expanding it
- **diagram/visual** — a simple inline SVG or leave it minimal if prose carries the point
- **explain** — two or three short paragraphs
- **action** — one thing to do or think about
- **eyebrow/pill** — context (e.g. part name)

Build with the block workflow and verify with build/check/shot.
