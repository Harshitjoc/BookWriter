# Blocks

The backlog. One entry per entry you intend to write, in any order. The `/block`
skill reads this to know what a page is about before it drafts anything. Nothing
here is printed.

A reference entry is short and answers one lookup. Keep the four lines:

- **What** becomes the opening answer.
- **Use when** decides whether the entry is worth having at all.
- **Action** becomes the box at the bottom.
- **Band** is usually "none": a reference entry leans on its table, not a drawing.
  Use a table for a set of fields, a list for a closed set.

---

## Part 1 · Codes and status

#### HTTP status codes
HTTP · none (table)
- **What:** the first digit says who is at fault. 4xx is the request, 5xx is the server.
- **Use when:** a call fails and you need the meaning, fast. **Skip when:** you already
  have the exact code and a search box.
- **Action:** "Before debugging a failing call, read its first digit."
- **Band:** none (a nine-row table of code, meaning, and next step).
